# Preserved v5 validation on solver 0.6.3

This is the unchanged validation report and figures used by releases 0.6.3 and 0.6.4, before the 0.6.5 wetting-age correction. The report records its exact build, calibration and data identities. Its predictive refits belong to that build; they are not reused for the corrected solver. Relative documentation links in the preserved report refer to its original `docs/validation` location.
