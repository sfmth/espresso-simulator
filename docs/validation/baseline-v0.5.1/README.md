# Preserved 0.5.1 validation

These files preserve the last validation of the v2 calibration before the 0.6.0
inventory correction and v3 refit. They were copied byte-for-byte from commit
`7b1d3a0`. The report records its original build identity; its cached v2 refits
are historical, as labelled there. The current report is
[one directory above](../m1-validation.md).

The copied report keeps its original relative links. To follow its companion
documentation in the matching revision, use the
[report at commit 7b1d3a0](https://github.com/sfmth/espresso-simulator/blob/7b1d3a004359af7471dc89416bd21be8e72b1ffc/docs/validation/m1-validation.md).

The separate [0.5.1 particle-input audit](../m11-particle-inputs.md) and its JSON
remain unchanged in their original locations. They evaluate fixed v2 parameters
on the 0.5.1 equations; their values are not v3 validation results.
